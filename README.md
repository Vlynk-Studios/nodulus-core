# ⚠️ This repository has been archived

**Nodulus has been renamed and migrated to a new scope, organization, and repository.**

All active development continues under the name **KerithJS**, published on npm under the `@kerith` scope and maintained in the [`@KerithJS`](https://github.com/KerithJS) organization on GitHub.

---

## Migration

| Before (Nodulus) | Now (Kerith) |
|---|---|
| `@vlynk-studios/nodulus-core` | [`@kerith/core`](https://www.npmjs.com/package/@kerith/core) |
| `@vlynk-studios/eslint-plugin-nodulus` | [`@kerith/eslint-plugin`](https://www.npmjs.com/package/@kerith/eslint-plugin) |
| `github.com/vlynk-studios/nodulus` | [`github.com/KerithJS/kerith`](https://github.com/KerithJS/kerith) |

---

## What was the last Nodulus release?

`@vlynk-studios/nodulus-core@1.8.1` is the final version published under this scope, introducing the HTTP logger (`useHttpLogger`). No further updates will be made to this repository.
